✨ Google Docs 原生直連轉調（先開複本・100% 不破版）

因為每位同工在 Google Docs 可能使用不同的字型、Tab 定位點或手動空白縮排來對齊歌詞，若轉成 .docx 再重新匯入容易發生字寬跑位。使用原生直連編輯會直接在 Google Docs 的文字節點上就地替換和弦，保留 100% 原始排版！

✅ 為什麼這個方式大家最放心、而且立刻就能看到真實效果？

• 權限只留在你自己的檔案：不需把雲端硬碟權限交給任何外部網站。
• 預設自動先開複本：按下轉調時會先在你的雲端建立新複本（例如 因祢十架 (F調)），原始歌譜完全不動！
• 就地微調文字節點：採用 insertText + deleteText，所有 Tab 鍵、縮排、微軟正黑體、灰底色塊原封不動！

📋 3 步驟在你的 Google Docs 直接開啟「🎵 敬拜歌譜轉調」選單

1. 打開你的 Google Docs 歌譜（或先手動「建立副本」）➡️ 點上方選單 「擴充功能」→「Apps Script」。
2. 點下方按鈕複製完整腳本，覆蓋貼上到編輯器後按 「儲存 (Ctrl+S)」，再點一次 「執行」 通過 Google 本人授權。
3. 回到歌譜重新整理，上方就會多出 「🎵 敬拜歌譜轉調 → 開啟無損轉調面板」，就能直接在 Google Docs 裡先開複本並一鍵轉調 + 下載乾淨 PDF！

若尚未設定 OAuth Client ID，可先點下方「模擬預覽就地編輯效果」確認實際替換指令，或切換到左側「⚡ 零設定 Apps Script」立即試用。
